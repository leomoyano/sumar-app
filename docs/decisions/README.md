# ADRs

Esta carpeta guarda decisiones arquitectónicas cortas y persistentes.

## Convención

- Formato: `ADR-XXXX-slug-kebab-case.md`
- Alcance: decisiones de arquitectura, documentación, workflow o límites importantes del sistema.
- Estilo: contexto → decisión → consecuencias.

## Cuándo abrir una nueva ADR

- cuando una decisión cambie cómo se estructura el repo
- cuando haya tradeoffs que convenga recordar más adelante
- cuando una convención tenga impacto en futuras implementaciones
- cuando haga falta justificar por qué una alternativa quedó descartada
